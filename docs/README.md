# docs/

Documentation and pictures for people, not for the game.

- [`START-HERE.md`](START-HERE.md): plain-language guide to the project, its folders and the common jobs. **Read this first.**
- `screenshots.png`: the picture shown on the GitHub page. Remake it with `tools/screenshots.sh` (Linux) or by taking screenshots yourself.
- `.gdignore`: an empty file that tells Godot to ignore this folder, so these files don't end up inside the game.
