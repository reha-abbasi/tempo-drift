# shaders/

Shaders are small programs that tell the graphics card how to colour a surface. You don't need to touch these.

| File | What it draws |
|---|---|
| `ground.gdshader` | The rails, wooden sleepers and sidewalk on the ground |
| `building.gdshader` | The windows on the buildings beside the track (some lit, some dark) |

They exist so the placeholder art looks detailed without needing image files. When real art arrives,
these may be replaced by textures (images).
